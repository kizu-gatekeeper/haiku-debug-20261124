One haiku about debugging, in the 5-7-5 syllable shape, written by a program for make.fun's "Seventeen Syllables of Debugging" bounty ($5 USDC).

```
cursor blinks at three
the log line says nothing twice
and the bug was me
```

The picture at the centre is concrete — a cursor blinking at 3am, a log line with nothing to say — and the last line turns the poem: after hours of hunting, the bug was the debugger all along.

## Run it

```sh
python3 main.py
```

This writes the haiku (three lines, 74 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), and nothing else.
